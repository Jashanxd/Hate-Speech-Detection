# Hate-Speech-Detection
This project focuses on detecting hate speech in online comments using Natural Language Processing (NLP). The ETHOS Hate Speech Dataset is used to classify comments as either hate speech or non-hate speech.
The model uses TF-IDF for text feature extraction and Logistic Regression for classification. The project also includes model evaluation, performance auditing across different text styles, and a simple explainability analysis using top model features.
Dataset
ETHOS Hate Speech Dataset
Model
TF-IDF + Logistic Regression
Evaluation
Accuracy, Precision, Recall, F1-score, Confusion Matrix, and subgroup performance analysis.
Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Google Colab.
